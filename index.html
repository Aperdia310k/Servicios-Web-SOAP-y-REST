Fundamentos de Interoperabilidad y Arquitectura Web

Aprende cómo los sistemas heterogéneos comunican datos sin fisuras utilizando contratos formales, esquemas rígidos en SOAP o flexibles en REST.

1. Evitar Ambigüedades

Sin un contrato formal (WSDL o OpenAPI), el cliente desconoce qué parámetros enviar, sus tipos de datos (enteros, cadenas, fechas) y el formato exacto de respuesta.

2. Garantizar Coherencia

Pequeñas diferencias (p. ej., formato DD/MM/YYYY vs YYYY-MM-DD) ocasionan fallos graves de parsing y errores en la lógica de negocio.

3. Reducir Acoplamiento

Permite establecer un acuerdo formal cliente-servidor independientemente de documentaciones informales propensas a quedar obsoletas.

Entorno SOAP (XML, WSDL, XSD)

W3C Standard

<Envelope> (Obligatorio)

Elemento raíz que define el documento como mensaje SOAP.

  • <Header>: Metadatos de control (autenticación, transacciones).
  • <Body>: Datos principales de la llamada/respuesta o <Fault> si ocurre error.

WSDL (Web Services Description)

Especificación de la interfaz mediante los elementos:

<types> (XSD)
<message>
<portType>
<binding>

XSD (XML Schema Definition)

Establece reglas de datos: tipos, cardinalidad (minOccurs, maxOccurs) y orden de elementos.

Entorno REST (JSON, OpenAPI, Schema)

HTTP Native

Semántica HTTP Restful

  • Métodos: GET (Lectura), POST (Creación), PUT (Reemplazo), PATCH (Parcial), DELETE (Borrado).
  • Cabeceras: Content-Type, Authorization, Accept.
  • Cuerpo: Predominantemente JSON.

OpenAPI / Swagger (YAML/JSON)

Contrato de la API con componentes clave:

paths (/recurso)
operations (get, post)
parameters (query/path)
responses (200, 400)

JSON Schema

Valida la estructura JSON: propiedad required, tipos (string, integer) y restricciones de rango/patrón.

4. Proceso de Validación y Mecanismos de Vinculación

Vinculación SOAP (Directa e Implícita)

El XML incluye espacios de nombres (xmlns) apuntando al XSD/WSDL. El motor de SOAP intercepta la petición y la valida antes de la ejecución. Si falla, el motor genera automáticamente un código de error:

<soap:Fault><faultcode>SOAP-ENV:Client</faultcode>...

Vinculación REST (Externa mediante Middleware)

La especificación OpenAPI se publica externamente. Un Middleware intercepta la petición JSON, la evalúa contra el JSON Schema y la rechaza si no cumple las especificaciones devolviendo:

HTTP/1.1 400 Bad Request
{"error": "ValidationFailed", "details": [...]}
